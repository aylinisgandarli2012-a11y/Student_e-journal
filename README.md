# Электронный журнал студентов (Python + Tkinter + JSON)

Учебное десктопное приложение для ведения электронного журнала с разделением ролей на **преподавателя** и **студентов**. Проект реализован на чистом Python с использованием стандартной библиотеки графического интерфейса Tkinter и JSON для персистентного хранения данных.

---

## 🚀 Основные возможности

- **Две роли пользователей:**
  - **Преподаватель (`sama`):** просмотр списка студентов, выставление и сохранение оценок (от 1 до 12), добавление новых студентов с автоматической генерацией пароля, удаление студентов, просмотр детальной статистики по каждому учащемуся.
  - **Студент:** просмотр собственного имени, списка всех оценок и расчет среднего арифметического балла.
- **Одно окно:** Навигация между экранами происходит динамически в рамках одного окна фиксированного размера (800×500 пикселей).
- **Сохранение данных:** Все изменения (студенты и их оценки) автоматически записываются в файл `students.json` и сохраняются после перезапуска программы.
- **Валидация данных:** Защита от ввода некорректных оценок (вне диапазона 1–12), пустых полей, дублирования логинов и попыток создания запрещенных логинов.
