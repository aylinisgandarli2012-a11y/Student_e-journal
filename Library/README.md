# Library Project

Простая консольная программа для управления книгами на Python с использованием ООП.

## Возможности
- Добавление книг
- Просмотр списка книг
- Выдача книги
- Возврат книги
- Консольное меню

## Структура файлов
- `main.py` — запуск программы и консольное меню
- `book.py` — класс `Book`
- `library.py` — класс `Library`
- `test_library.py` — тесты (`pytest`)
- `README.md` — описание проекта

## Запуск в PyCharm
1. Создайте проект и добавьте указанные файлы.
2. Установите библиотеку для тестов через терминал PyCharm:
   ```bash
   pip install pytest
